Rule-Based Analysis

Turbidity sets the base category. An ESP32 thermal-anomaly flag raises it to Poor, and breached active threshold rules can raise it to Fair, Poor, or Critical. The most severe applicable status is retained. If turbidity is missing, the result starts as Unknown unless another threshold rule or the thermal flag classifies the reading. 

status = classify_turbidity(turbidity_ntu)
if thermal_anomaly > 0:
    status = max_severity(status, "Poor")

for rule in active_threshold_rules:
    if measured_value_breaches(rule):
        status = max_severity(status, rule.status)

ESP32 Sensor Calculations

The ESP32 averages 20 ADC samples and converts its 12-bit reading to voltage with voltage = average_adc × 3.3 / 4095. It sends calculated sensor values to the app. The app preserves supplied values and fills a missing derived value only when its source measurement is available. Clamp operations round to an integer and restrict the result to the stated range.

Turbidity

turbidity_ntu = clamp(-1120.0 * voltage + 3000.0, 0, 3000)
tss = clamp(turbidity_ntu * 0.5, 0, 10000)
particle_level = clamp((turbidity_ntu / 1000) * 100, 0, 100)
clarity = 100 - particle_level

The sketch defaults to TURBIDITY_SLOPE = -1120.0 and TURBIDITY_INTERCEPT = 3000.0. These are example calibration coefficients, not universal sensor constants.

TDS and Derived Estimates

compensation = max(0.1, 1 + 0.02 * (water_temp_c - 25))
v = adc_voltage / compensation
tds_ppm = clamp((133.42*v^3 - 255.86*v^2 + 857.39*v) * 0.5 * TDS_FACTOR, 0, 10000)
conductivity = clamp(tds_ppm * 2, 0, 20000)
ionic_content = clamp(tds_ppm / 10, 0, 100)
salinity = clamp(tds_ppm / 1000, 0, 100)

TDS_FACTOR defaults to 1.0. Conductivity, ionic content, and salinity are approximate conversions from TDS, not independent sensor measurements.

pH

ph = clamp(7.0 + (PH7_VOLTAGE - voltage) * PH_SLOPE, 0, 14)
stored_ph = ph * 100
acidity = clamp((7 - ph) / 7 * 100, 0, 100)
alkalinity = clamp((ph - 7) / 7 * 100, 0, 100)
ph_stability = clamp(100 - (max_recent_ph - min_recent_ph) * 2, 0, 100)

PH7_VOLTAGE defaults to 2.50 V and PH_SLOPE to 5.70; calibrate them with buffer solutions. pH is stored ×100, and stability uses up to 30 recent samples on that scale.

Temperature

temperature = water_temp_c * 100
ambient_temperature = air_temp_c * 100
change_rate = ((water_temp_c - previous_water_temp_c) / elapsed_minutes) * 100
thermal_anomaly = water_temp_c > 40 or water_temp_c < 5
                  or abs(water_temp_c - air_temp_c) > 10

Water and ambient temperature are stored ×100; change rate is °C per minute ×100. The ambient-difference check needs a valid DHT reading. Water quality index is not calculated because the sketch does not define a WQI formula.

Water Quality Assessment

The base turbidity categories are Good through 5 NTU, Fair above 5 through 10 NTU, and Poor above 10 NTU.

if turbidity_ntu is None:
    status = "Unknown"
elif turbidity_ntu <= 5:
    status = "Good"
elif turbidity_ntu <= 10:
    status = "Fair"
else:
    status = "Poor"

The resulting status is saved with the reading and assessment. Poor or Critical readings trigger alerts; configured threshold breaches also generate alerts with their rule severity.
